### 6. Titanic Survival Prediction

A classification project that predicts whether a Titanic passenger would have survived based on demographic and travel information.

**Models evaluated:**

- Logistic Regression
- Random Forest Classifier

**Selected model:**

- Random Forest
- Accuracy: 80.45%
- Precision: 72.97%
- Recall: 78.26%
- F1-score: 75.52%
- ROC-AUC: 84.05%

**Main technologies:**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Joblib
- Jupyter Notebook

[View Project](./Titanic-Survival-Prediction)
