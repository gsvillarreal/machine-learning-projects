# 🎓 Student Performance Prediction

Machine Learning project that predicts students' exam scores using demographic, academic, and lifestyle information.

---

## 📌 Project Overview

This project uses Machine Learning to estimate a student's final exam score based on several factors such as:

- Study hours
- Attendance
- Previous scores
- Sleep hours
- Internet access
- Family income
- Teacher quality
- Motivation level
- Physical activity
- And more...

The project includes complete data analysis, preprocessing, model training, evaluation, and prediction.
