# 🏠 House Price Prediction

## Overview

This project predicts house prices using Machine Learning techniques with Python and Scikit-Learn.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Dataset

The project will use a housing dataset for training and evaluation.

## Goal

Build a regression model capable of predicting house prices from property features.
