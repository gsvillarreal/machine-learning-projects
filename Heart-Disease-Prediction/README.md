# ❤️ Heart Disease Prediction

## 📌 Project Overview

This project predicts whether a patient is likely to have heart disease using Machine Learning models trained on clinical data.

The project includes:

- Exploratory Data Analysis (EDA)
- Data preprocessing
- Logistic Regression model
- Random Forest model
- Model evaluation
- Interactive web application with Streamlit

---

## 📊 Dataset

Heart Disease Dataset

Target variable:

- 0 = No Heart Disease
- 1 = Heart Disease

Number of samples:

- 1025 patients

Number of features:

- 13 clinical features
